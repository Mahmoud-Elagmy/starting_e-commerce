# 🖋️ Pen Store E-Commerce Platform

A modern, responsive e-commerce frontend interface dedicated to premium writing instruments. This project focuses on delivering a highly interactive user experience through advanced CSS layouts and fluid animations.

## 🚀 Live Demo
> **[https://mahmoud-elagmy.github.io/starting_e-commerce/]**

## ✨ Key Features
* **Advanced UI Animations:** Smooth, custom CSS keyframe animations to enhance product discovery.
* **Persistent Interaction States:** Optimized hover states that maintain 100% completion during user interaction for a seamless feel.
* **Dynamic Layout Swapping:** Complex flexbox configurations allowing elements to smoothly swap positions based on viewport size and user interaction.
* **Responsive Design:** Fully fluid layout that adapts flawlessly from mobile screens to large desktop monitors.

## 🛠️ Tech Stack
* **HTML5:** Semantic structuring for accessibility and SEO.
* **CSS3:** Custom keyframe animations, transitions, and Flexbox architecture.
* **JS:** Simple scropts for buttons and hover, action and focus states
* **Bootstrap:** Rapid grid deployment and responsive utility classes.
